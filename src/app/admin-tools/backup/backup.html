This time is stored only in this browser, so it will not show backups taken from another computer.

Restoring does not replace anything automatically. The backup must be run on an empty database. Never run it on the live school database.

What is in the file

Every table and all data: students, teachers, attendance, fees, ledger, settings, and also user accounts with their password hashes.

Keep the file private. Anyone who has it can read all school records.

How often

  • Before the start of each term
  • Before any software upgrade
  • At least once a week

Where to keep it

Do not keep it only on this computer. Copy it to a pen drive or a cloud drive as well, so a computer failure does not lose both the database and its backup.

How to restore

Create an empty PostgreSQL database, then run:

psql -d <database> -f <backup-file>.sql

Or open the file in pgAdmin or DBeaver and run it.
